# Problema-para-chamar-de-seu

Trabalho da disciplina  EMA235 - Otimização Aplicada à Engenharia Aeroespacial

O trabalho consiste na busca pela distribuição ideal de passagens do trem de passageiros da Vale para obter a maior renda, em dois cenários distintos: demanda infinita e demanda finita.

O trabalho foi executado em Python e utiliza como método de Otimização a Programação Linear Inteira (PLI).
